# Agent 高含金量链路参考

## 排名原则

按闭环程度、失败处理、证据密度、业务影响、可落地性和面试可防守性评分，不按框架热度或 star 排名。“用了某组件”不是链路；必须能回答输入、决策、状态/副作用、输出和失败后的行为。

## S 级

### 1. 长程任务与持久化编排

任务分解 → 状态机/图 → checkpoint/store → worker/Tool 执行 → 超时/取消/重试 → 恢复/续跑 → 人工审核或最终交付。重点证据：状态 schema、checkpoint 写入与读取、任务 ID、幂等键、补偿或死信处理。

### 2. 工具调用可靠性与安全边界

模型决策 → Tool schema/参数校验 → 权限/策略 → 超时与退避 → 外部副作用 → 结果校验/审计。重点证据：Pydantic/JSON schema、timeout、retry/backoff、circuit breaker、idempotency、sandbox、approval、audit log。

### 3. 评测与回归体系

任务数据集 → 运行轨迹 → grader/规则/模型评审 → 成功率、事实性、引用、Tool 成功率、成本、延迟 → 失败样本回流 → 版本回归。重点证据：eval cases、trajectory、评分函数、阈值、CI 或报告。

## A 级

- **记忆与上下文生命周期**：短期状态、长期记忆、摘要压缩、检索/写入策略、来源、时间衰减、租户隔离和删除。
- **可观测性与成本/延迟治理**：trace/span、事件日志、token/费用、瓶颈、模型路由、降级、预算和告警。
- **多 Agent 与人机协同**：角色边界、任务分解、共享状态、人工接管、冲突处理和回滚。
- **数据/RAG 质量链路**：增量 ingestion、知识版本、权限过滤、召回/重排评测、引用约束和可回溯性。
- **安全与治理**：提示词注入防护、Tool 权限、敏感数据脱敏、租户隔离、审计和策略引擎。

## B 级

基础向量检索、prompt 模板、单次 LLM 调用、简单 Tool wrapper、只展示多个角色而没有状态/失败/评测证据，只能作为支撑能力。若补齐质量评测、权限、增量更新或可靠性，可升到 A 级。

## 评分提示

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 闭环 | 单点调用 | 有输入输出 | 有状态、副作用和交付闭环 |
| 故障处理 | 无 | 有通用重试 | 有分类、退避、幂等、补偿/人工接管 |
| 证据 | README/命名 | 少量源码 | >=5 个可定位源码证据 |
| 业务价值 | 技术演示 | 场景明确 | 有用户/团队结果和验证方式 |
| 可防守性 | 只能说用了框架 | 可解释局部 | 能讲边界、取舍和个人角色 |
